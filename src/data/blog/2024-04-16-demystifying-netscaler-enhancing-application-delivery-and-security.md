NetScaler (Citrix ADC) is a core platform for modern application delivery and protection. It combines traffic optimization, resiliency, and security controls into a single operational layer.

## Key Delivery Capabilities

- **Load balancing** to distribute traffic and improve availability
- **Traffic management** policies for user- and app-aware routing
- **SSL offloading** to reduce backend overhead
- **GSLB** for multi-site resiliency and failover

## Security Value

NetScaler also provides a security control plane through integrated WAF and policy enforcement mechanisms to help mitigate common application-layer attacks.

## Why It Matters

For teams running business-critical services, NetScaler can improve both user experience and defensive posture when configured with clear architecture patterns and ongoing policy hygiene.

This post serves as a foundational reference before diving into implementation-level hardening and optimization workflows.
